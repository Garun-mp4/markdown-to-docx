# Markdown → DOCX

Небольшое веб-приложение для преобразования Markdown в редактируемый DOCX по единому академическому профилю MVP.

## Возможности

- Загрузка `.md` либо ZIP-проекта, содержащего Markdown и изображения.
- Дополнительный ZIP с ресурсами для отдельного Markdown-файла.
- Разрешение относительных ссылок и локальных абсолютных путей по имени файла; при совпадениях приложение просит выбрать ресурс.
- Вставка HTTPS-изображений с проверкой общедоступного адреса сервера, ограничениями размера и поддерживаемого формата.
- Настройка верхнего и нижнего колонтитулов: пустой, статический текст или автоматический номер страницы.
- Оформление заголовков, абзацев, выделенного и зачёркнутого текста, ссылок, цитат, вложенных и нумерованных списков, кода, таблиц и изображений.
- Поддержка списков задач (`- [x]` / `- [ ]`), горизонтальных разделителей и таблиц GitHub Markdown и Pandoc simple table.
- Явный разрыв страницы через отдельную строку `<!-- pagebreak -->`.
- Временная обработка файлов без постоянного хранения на сервере.

## Запуск

Требуется Python 3.10 или новее.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Откройте `http://127.0.0.1:5000`.

Для разработки и тестов:

```powershell
python -m pip install pytest
python -m pytest
```

## Профиль документа

- A4; поля: слева 30 мм, справа 15 мм, сверху и снизу 20 мм.
- Times New Roman, основной текст 12 pt, межстрочный интервал 1,5, отступ первой строки 12,5 мм.
- Заголовки H1–H6: 20/18/16/14/13/12 pt, полужирные, с левым отступом 0/5/10/15/20/25 мм.
- Табличные заголовки выделяются полужирным и центрируются; строки данных выравниваются слева.
- Подпись таблицы распознаётся перед таблицей по шаблону `Таблица 1 — Название`; подпись рисунка — после изображения по шаблону `Рисунок 1 — Название`.

Цитаты получают левую вертикальную линию и дополнительный отступ. Маркеры нумерованных списков учитывают заданный начальный номер и сбрасываются в новом списке. Таблицы без распознанной подписи остаются единым объектом Word: редактор переносит их по страницам и повторяет строку заголовков. Длинные таблицы с подписью разбиваются по оценке высоты строк: каждый сегмент начинается с повторённого заголовка столбцов, а последующие — с подписи «Продолжение таблицы N».

Конвертер поддерживает CommonMark и расширения для таблиц, зачёркивания и списков задач. Произвольный HTML, математическая разметка и сноски не входят в профиль MVP.

## Ограничения

- Титульный лист и автоматическое содержание не создаются.
- Для ZIP-проекта с несколькими `.md` нужно выбрать основной Markdown-файл.
- Изображения до 10 МБ каждое; суммарный объём обработанных изображений до 30 МБ. Входящий запрос ограничен 50 МБ, распакованный ZIP — 100 МБ.
- Поддерживаются растровые PNG, JPEG, GIF, BMP, TIFF и WEBP. SVG и внешние ресурсы кроме HTTPS не поддерживаются.
- Веб-приложение рассчитано на локальный запуск или развёртывание за доверенным HTTPS reverse proxy; перед публичным запуском настройте серверный WSGI и сетевые лимиты.
