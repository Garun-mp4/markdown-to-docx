# Markdown → DOCX

Локальное веб-приложение для преобразования Markdown в редактируемый документ Word с академическим профилем оформления.

## Возможности

- Загрузка файлов .md или ZIP-проекта с одним либо несколькими Markdown-файлами.
- Добавление изображений по одному, списком, папкой или ZIP-архивом ресурсов. Для файлов из папки сохраняются относительные пути; при совпадении только по имени приложение использует единственный файл или просит выбрать нужный.
- Проверка форматов и размеров с сообщениями рядом с соответствующей областью. Отсутствующие изображения не пропускаются молча.
- Конструктор верхнего и нижнего колонтитулов с предпросмотром листа A4. Для номера страницы можно задать лист начала показа и выбрать продолжение общего счёта или перезапуск с 1.
- Редактирование профиля страницы, основного текста, заголовков, списков, цитат, кода, таблиц, изображений, подписей, ссылок и колонтитулов. Кнопка возврата восстанавливает исходные параметры; «Новый файл» сбрасывает форму и настройки.
- Поддержка заголовков, абзацев, жирного и курсивного текста, зачёркивания, ссылок, вложенных нумерованных и маркированных списков, цитат, блоков и фрагментов кода, таблиц, изображений, подписей, горизонтальных линий и списков задач.
- Таблицы без подписи остаются единым объектом Word с повторяемой строкой заголовков. Длинные подписанные таблицы разбиваются с повтором заголовков и подписью «Продолжение таблицы N».
- Явный разрыв страницы задаётся директивой pagebreak в HTML-комментарии.
- Файлы обрабатываются временно и не сохраняются приложением после ответа.

## Запуск

Требуется Python 3.10 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000.

Для разработки и проверок:

```powershell
python -m pip install pytest
python -m pytest
ruff check app.py converter.py docx_profile.py tests
```

## Исходный профиль

- Страница A4, 210 × 297 мм; поля: слева 30 мм, справа 15 мм, сверху и снизу 20 мм.
- Основной текст: Times New Roman, 12 pt, чёрный цвет, выравнивание слева, интервал 1,5, отступ первой строки 12,5 мм.
- Заголовки H1–H6: Times New Roman, 20/18/16/14/13/12 pt, полужирные, чёрные, с отступами 0/5/10/15/20/25 мм.
- Табличная строка заголовков полужирная и выравнивается по центру; ячейки данных выравниваются слева.
- Подпись таблицы распознаётся перед ней по шаблону «Таблица 1 — Название»; подпись рисунка — после изображения по шаблону «Рисунок 1 — Название».

При выборе «Новый файл» профиль и колонтитулы возвращаются к этим начальным значениям. Приложение не хранит пользовательские настройки между документами.

## Ограничения

- Титульный лист и автоматическое содержание не создаются.
- Для ZIP-проекта с несколькими .md нужно выбрать основной Markdown-файл.
- Markdown должен быть в кодировке UTF-8 и не превышать 5 МБ; общий размер загружаемых файлов ограничен 200 МБ, распакованный объём ZIP-файлов — 200 МБ.
- Изображения до 30 МБ каждое; суммарный объём обработанных изображений до 200 МБ. Изображения выше 20 Мп уменьшаются при обработке; исходное разрешение ограничено 60 Мп. Высота крупных изображений ограничивается с сохранением пропорций, чтобы они не занимали почти всю страницу.
- Поддерживаются PNG, JPEG, GIF, BMP, TIFF и WEBP. SVG не поддерживается. Удалённые изображения принимаются только по HTTPS с проверкой общедоступного адреса сервера.
- Конвертер поддерживает CommonMark, таблицы, зачёркивание и списки задач. Произвольный HTML, математическая разметка и сноски не входят в текущий профиль.
- Для публичного размещения настройте серверный WSGI и сетевые лимиты.
